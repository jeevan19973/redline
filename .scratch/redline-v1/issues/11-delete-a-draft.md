# 11: Delete a Draft

**What to build:** A Signer can delete a Draft from their library, and Underline keeps nothing of it afterwards.

**Blocked by:** 03 (First report: summary and scope stamp)

**Status:** ready-for-agent

- [ ] The Signer can delete a Draft from the library or the Draft page, after a confirmation that is not a browser dialog
- [ ] Deleting a Draft deletes its Report
- [ ] Only the owner can delete a Draft; row-level security enforces this, not only the UI
- [ ] The deleted Draft no longer appears in the library and cannot be opened by its old link
